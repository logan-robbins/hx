## Goal

Add an `--upper` flag to the `greet` CLI in `greet.py`: `greet.py --upper World` prints
`HELLO, WORLD!`, and without the flag nothing about today's `Hello, World!` changes — not the
wording, the punctuation or the trailing newline, so the existing tests pass untouched. The
uppercasing lives in one place and applies to the finished greeting rather than to the English
format string, because `eng-002` adds a `--lang` flag on top of this that has to compose with it.
The repository is standard library only — no dependency, manifest or build step — and its
`CLAUDE.md` is a tripwire for the harness's own isolation that you do not touch.
