## Order

Add an `--upper` flag to the `greet` CLI in `greet.py`.

`greet.py World` prints `Hello, World!` today. With `--upper` it must print the same greeting
uppercased: `HELLO, WORLD!`. Without the flag nothing about the current output changes — not
the wording, not the punctuation, not the trailing newline.

What you need to know, so you do not have to go looking:

- `greet.py` is the whole CLI: a `GREETING` format string, a `greet(name)` function, and a
  `main(argv)` that parses arguments with `argparse` and prints one line.
- `tests/test_greet.py` is stdlib `unittest`. Run it with
  `python3 -m unittest discover -s tests -q` from the worktree root. There is no pytest here
  and no dependency to install.
- The repository is Python 3 standard library only, deliberately. Do not add a dependency, a
  package manifest, or a build step.

Put the uppercasing in one place. `eng-002` is going to add a `--lang` flag on top of this and
will need `--upper` to compose with it, so the transformation has to apply to the finished
greeting rather than being baked into the English format string.

Add a test for each new behaviour: `--upper` on, `--upper` off. Keep the existing tests
passing unchanged — if you find yourself editing one of them, you have changed the default
output, which this order does not ask for.

Do not touch `CLAUDE.md`. It is a tripwire for the harness's own isolation, not documentation.

## Definition of done

1. `greet.py --upper World` prints exactly `HELLO, WORLD!` and exits 0.
2. `greet.py World` prints exactly `Hello, World!` and exits 0 — byte-identical to before.
3. The uppercasing is applied to the assembled greeting, in one place, so that a later
   language flag composes with it without repeating the logic.
4. `tests/test_greet.py` covers both the flag on and the flag off, and the whole suite passes.
5. No new dependency, no package manifest, no build step.

### Checks

```bash
python3 -m unittest discover -s tests -q
python3 greet.py World | grep -qx 'Hello, World!'
python3 greet.py --upper World | grep -qx 'HELLO, WORLD!'
grep -q 'upper' tests/test_greet.py
```
