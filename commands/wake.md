# /hx:wake — talk to the Partner

The human's message to the Partner follows: `$ARGUMENTS`. Deliver it with
`hx wake partner` plus that text, then confirm it was sent. If no message was given, ask
what they want to tell the Partner instead of sending an empty wake. If `hx` is not
installed or no instance exists, point at `/hx:setup`.
